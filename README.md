##  Project Overview
This project focuses on building a **Data Warehouse system** and implementing **ETL, OLAP, Reporting, and Data Mining** techniques based on the **Traffic Crashes Dataset**.  

The dataset provides detailed information about traffic accidents, including **time, location, weather conditions, road status, causes, and damage levels** — making it a practical source for developing an analytics system to support **traffic safety decision-making**.

---

##  Project Phases

### 1. Data Warehouse Design
- Data exploration, preprocessing, and attribute selection.  
- Designed **Snowflake schemas** with Dimension and Fact tables.  
- Validated data using SQL queries.  

### 2. ETL with SSIS
- Built ETL workflows with **SQL Server Integration Services (SSIS)**.  
- Created and loaded Dimension/Fact tables with defined relationships.  
- Executed and validated the ETL pipeline.  

### 3. OLAP with SSAS
- Configured **SQL Server Analysis Services (SSAS)**.  
- Built **Cubes, Dimensions, Hierarchies, and Measures**.  
- Performed analytical queries using **MDX** and Excel Pivot.  

### 4. Reporting & Visualization
- Designed and published dashboards with **Power BI**.  
- Built visual reports in **Locker Studio** using extracted CSV data.  

### 5. Data Mining & Predictive Modeling
- Performed feature selection and redundancy elimination.  
- Developed predictive models with **Logistic Regression, Random Forest, XGBoost, and LightGBM**.  
- Evaluated model performance for accident risk prediction.  

---

## Final Outcome
Delivered an **end-to-end BI & Data Analytics pipeline**: from preprocessing and warehouse design, through OLAP and reporting, to predictive modeling.  

This project demonstrates a complete **Business Intelligence solution** that can be applied to improve **traffic safety management**.
